# MPilukov/homebrew-tap

Homebrew formulae for small tools by MPilukov.

```sh
brew install mpilukov/tap/<formula>
```

| Formula | What it is |
|---|---|
| [iterm-layout](https://github.com/MPilukov/iterm-layout) | Save and restore iTerm2 windows, split panes, folders and Claude Code sessions |

menuki has its own tap: `brew install mpilukov/menuki/menuki`.
